# سينماك — منصة مشاهدة للمحتوى المرخّص

مشروع بداية عربي RTL باستخدام Next.js + Supabase.

## الموجود
- صفحة رئيسية مع عنوان مميز وأقسام أحدث الإضافات والأكثر مشاهدة (الأكثر مشاهدة يعتمد حاليًا على `views_count` الذي يحتاج تحديثًا من خدمة موثوقة).
- تفاصيل المحتوى مع مشغل HTML5 للفيديو وروابط الإعلان الترويجي.
- إنشاء حساب وتسجيل دخول.
- صفحة حساب وقائمة المشاهدة لاحقًا.
- لوحة إدارة لإضافة/تعديل/حذف المحتوى، مقيدة بدور `admin` في جدول profiles.
- SQL لإنشاء الجداول وسياسات RLS.
- API أساسي لإضافة عنوان لقائمة المشاهدة وسجل المشاهدة.

## التشغيل
1. تحتاج Node.js 20+ في بيئة تدعم Next.js.
2. انسخ `.env.example` إلى `.env.local`.
3. أنشئ مشروع Supabase، وانسخ Project URL والمفتاح العام publishable/anon إلى `.env.local`.
4. من Supabase SQL Editor شغّل `supabase/schema.sql`.
5. أنشئ حسابًا من `/register` أو Supabase Auth.
6. من Authentication > Users انسخ UUID الخاص بحسابك، ثم شغّل:
   `update public.profiles set role='admin' where id='YOUR_AUTH_USER_UUID';`
7. شغّل `npm install` ثم `npm run dev`.
8. افتح `/` للموقع، `/register` للتسجيل، `/profile` لحساب المستخدم، `/admin` للوحة الإدارة.

## تنبيهات مهمة
- هذا starter يحتاج اختبارًا فعليًا وإصلاحات محتملة قبل الإنتاج؛ لم يتم تشغيل build أو اختبار تكامل حي مع Supabase ضمن تجهيز الملفات.
- مشغل HTML5 يدعم عادةً روابط MP4 مباشرة متوافقة. روابط YouTube/Vimeo أو روابط HLS قد تحتاج مشغلًا/إعدادًا مختلفًا؛ لا تلصق رابط صفحة فيديو عادي في حقل ملف الفيديو.
- لا ترفع ملفات فيديو كبيرة إلى قاعدة البيانات. استخدم خدمة فيديو/CDN أو تخزين مناسبًا مع التحكم بالوصول، وقد لا تكفي حدود التخزين/النقل المجانية للعرض العام.
- لا تضف إلا محتوى تملك حقوق عرضه أو لديك ترخيص واضح له.
- قبل تشغيل الإعلانات، جهز سياسة الخصوصية وشروط الاستخدام وصفحة تواصل، وتحقق من شروط شبكة الإعلانات.
- تحقق من شروط الاستضافة الحالية؛ Vercel Hobby موجه للاستخدام الشخصي غير التجاري، لذا اختر خطة تسمح بالاستخدام التجاري عند تحقيق الدخل.
- راجع سياسات Supabase والتكاليف وحدود الخطة المجانية قبل النشر العام.
